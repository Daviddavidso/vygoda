# ВЫГОДА — витрина финансовых офферов

Тёмный брутал-лендинг с подборкой финансовых продуктов: займы МФО, дебетовые и
кредитные карты банков. Стиль сделан по референсу клиента: чёрный холст, гигантский
конденс-шрифт, бордовый маркер поверх типографики.

Живая версия: https://daviddavidso.github.io/vygoda/

## Что внутри

```
index.html   разметка
styles.css   вся вёрстка и тема
script.js    фильтры, аккордеон, бегущая строка, меню
data.js      ← ВЕСЬ КОНТЕНТ ЗДЕСЬ
fonts/       Oswald, Golos Text, JetBrains Mono (локально, без внешних запросов)
favicon.svg  иконка вкладки
```

Ни сборки, ни зависимостей: обычные файлы, которые открываются в браузере.

## Как поменять офферы

Открываешь `data.js`, правишь массив `OFFERS`. Один объект — одна карточка:

```js
{ cat: 'loans', partner: 'Займер', title: 'Займ на карту', badge: 'ТОП',
  url: 'https://партнёрская-ссылка?erid=2W5zFHwA2h6' }
```

- `cat` — `loans` (займы), `debit` (дебетовые карты), `credit` (кредитные карты);
- `badge` — плашка `ТОП` / `НОВОЕ` / `СКОРО`, можно не указывать;
- `url` — боевая партнёрская ссылка. **Токен erid вытаскивается из ссылки
  автоматически** и печатается в карточке — отдельно вписывать не нужно.
  Пока ссылки нет, кнопка ведёт в Telegram;
- `bullets` — если у конкретного оффера есть реальные условия, перечисли их здесь.
  Без этого поля подставляются нейтральные факты из `DEFAULTS`.

Название проекта и ссылки на Telegram — объект `SITE` в начале файла.
Категории — `CATEGORIES`, шаги — `STEPS`, вопросы — `FAQ`.
Цифры в блоке «Что за этим стоит» считаются от каталога сами.

### Почему в карточках нет ставок и сроков

Это сделано намеренно. Ставки, лимиты и ПСК меняются, а недостоверная реклама
финансовых услуг — это штраф. Пока партнёрка не прислала точное условие, цифру
писать нельзя. Появилось — добавляешь в `bullets` конкретного оффера.

## Цвета

Тема живёт в переменных в начале `styles.css`:

| Переменная | Значение | Что это |
|---|---|---|
| `--bg` | `#0A090B` | фон страницы |
| `--wine` | `#6E0F1D` | глубокий бордовый (бегущая строка, блок CTA) |
| `--accent-fill` | `#C1123F` | заливка кнопок |
| `--accent-text` | `#F43F5E` | акцентный текст и цифры |

Все пары проверены на контраст по WCAG AA: текст ≥ 4.5:1, рамки и элементы
управления ≥ 3:1. Меняешь палитру — проверяй заново, иначе часть текста пропадёт
на тёмном фоне у людей со слабым зрением и на телефоне под солнцем.

## Локальный запуск

```bash
python3 -m http.server 4450 --directory ~/vygoda-landing
```

Открыть http://localhost:4450

## Заливка на хостинг (FTP)

Сборка не нужна: кидаешь в корень сайта `index.html`, `styles.css`, `script.js`,
`data.js`, `favicon.svg` и папку `fonts/`.

## Доступность

- один `h1`, корректная иерархия заголовков, пять ориентиров (header / nav / main / footer / nav);
- всё управляется с клавиатуры, белая рамка фокуса 3px с отступом;
- бегущая строка останавливается кнопкой и не стартует при системной настройке
  «меньше движения»;
- фильтры на `aria-pressed`, счётчик результатов озвучивается через `role="status"`;
- размеры кликабельных зон от 44×44, поддержаны режимы высокого контраста и печати.
