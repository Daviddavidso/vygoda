# АБУЗИЩЕ — лендинг-витрина офферов

Тёмный брутал-лендинг под абуз бонусов: букмекеры, казино, крипта, банковские карты.
Стиль сделан по референсу клиента (чёрный холст, гигантский конденс-шрифт, бордовый маркер).

Живая версия: https://daviddavidso.github.io/abuzz/

## Что внутри

```
index.html   разметка
styles.css   вся вёрстка и тема
script.js    фильтры, аккордеон, бегущая строка, меню
data.js      ← ВЕСЬ КОНТЕНТ ЗДЕСЬ
fonts/       Oswald, Golos Text, JetBrains Mono (локально, без внешних запросов)
favicon.svg  иконка вкладки
```

Ни сборки, ни зависимостей: это обычные файлы, которые открываются в браузере.

## Как поменять офферы

Открываешь `data.js`, правишь массив `OFFERS`. Один блок `{ ... }` — одна карточка.

```js
{
  id: 'offer-01',
  brand: 'Название конторы',
  cat: 'bk',                       // bk | casino | crypto | bank
  amount: '20 000',                // крупное число в карточке
  unit: '₽',                       // ₽ / $ / FS / %
  read: 'бонус двадцать тысяч рублей',   // как это читает голосовой помощник
  title: 'Суть оффера одной строкой',
  badge: 'ТОП',                    // ТОП | НОВОЕ | СКОРО | '' (без плашки)
  terms: [
    ['Депозит', 'от 100 ₽'],
    ['Отыгрыш', 'не нужен'],
  ],
  payout: 'до 3 500 ₽ за лид',
  url: 'https://твоя-партнёрская-ссылка',   // пусто → кнопка ведёт в Telegram
}
```

Категории в фильтре задаются в `CATEGORIES`, цифры — в `STATS`, вопросы — в `FAQ`,
ссылки на канал и чат — в `CONTACTS`. Сохранил файл, обновил страницу — готово.

## Цвета

Тема живёт в переменных в начале `styles.css`:

| Переменная | Значение | Что это |
|---|---|---|
| `--bg` | `#0A090B` | фон страницы |
| `--wine` | `#6E0F1D` | глубокий бордовый (бегущая строка, блок CTA) |
| `--accent-fill` | `#C1123F` | заливка кнопок |
| `--accent-text` | `#F43F5E` | акцентный текст и цифры |

Все пары цветов проверены на контраст по WCAG AA: текст ≥ 4.5:1, рамки и элементы
управления ≥ 3:1. Если будешь менять палитру — проверь заново, иначе часть текста
пропадёт на тёмном фоне у людей со слабым зрением и на телефоне под солнцем.

## Локальный запуск

```bash
python3 -m http.server 4450 --directory ~/abuzz-landing
```

Открыть http://localhost:4450

## Заливка на хостинг клиента (FTP)

Файлов немного, льются как есть — сборка не нужна. Достаточно закинуть в корень сайта:
`index.html`, `styles.css`, `script.js`, `data.js`, `favicon.svg` и папку `fonts/`.

## Доступность

- один `h1`, корректная иерархия заголовков, пять ориентиров (header / nav / main / footer / nav);
- всё управляется с клавиатуры, белая рамка фокуса 3px с отступом;
- бегущая строка останавливается кнопкой и не стартует при системной настройке
  «меньше движения»;
- фильтры на `aria-pressed`, счётчик результатов озвучивается через `role="status"`;
- размеры кликабельных зон от 44×44, поддержаны режимы высокого контраста и печати.
